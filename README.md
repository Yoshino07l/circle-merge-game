# 合成圆圆

11 张照片的网页合成小游戏：圆形碰撞、轻微弹跳、低摩擦。无需安装依赖，没有外部图片、字体或脚本服务。

## 游玩

本地：下载完整文件夹，双击 `index.html`。

电脑：移动鼠标瞄准，点击投放；左右方向键微调，空格投放。

手机：按住棋盘拖动瞄准，松手投放。

同级圆球相碰后合成更大一级；两个最高等级相碰会消失并获得奖励。越过警戒线且持续超时后结束。本机最高分保存在当前浏览器，没有在线排行榜。

## 发布到 GitHub Pages

本文件夹中的文件放在仓库根目录，保留 `assets/photos/` 文件夹结构及 `.nojekyll` 文件。

1. 打开仓库的 **Settings → Pages**。
2. **Source** 选择 **Deploy from a branch**。
3. **Branch** 选择 **main**，文件夹选择 **/(root)**，点击 **Save**。
4. 等待 GitHub 完成发布；使用 Pages 页面显示的实际网址分享。

上传代码不代表网站已经发布成功。此仓库不需要额外构建流程。

## 换图和调整参数

覆盖 `assets/photos/01.jpg` 到 `11.jpg`；01 为最小等级，11 为最大等级。当前按原照片文件名升序安排，不是实际体型或体重排名。

在 `config.js` 中调整游戏标题、等级半径、合成分数和物理参数。当前球与球弹跳为 `0.22`、墙与地面弹跳为 `0.18`、接触摩擦为 `0.18`。同名换图后修改 `assetRevision` 并重新发布，可避免旧图片缓存。

详细说明见 [替换图片说明.md](替换图片说明.md)。
